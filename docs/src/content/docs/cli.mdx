The current published Relicta CLI is **v4.2.0**. This page describes that release. v5 capabilities in the source repository, including drafting customer notes in a coding-agent session and saving them through MCP, are not available in v4.2.0.

Install the CLI using the [installation guide](/install), then run `relicta --help` or `relicta <command> --help` for options supported by your installed version.

## Recommended: review the full workflow

`relicta release --dry-run` previews the release without making changes. Running `relicta release` executes the workflow, including versioning, notes, approval, and publishing. Publishing can create a Git tag and run configured plugins; review the preview and repository configuration before running it.

```bash
relicta release --dry-run
relicta release
```

For unattended automation, `--yes` skips the interactive approval prompt. Use it only when your CI policy provides the required approval outside that prompt.

## Step-by-step workflow

Use the individual commands when you want to inspect and control each stage:

```bash
# Detect the repository and write .relicta.yaml if it does not exist
relicta init

# Analyze changes and recommend a version
relicta plan

# Apply the chosen version to configured version files
relicta bump

# Generate release notes from repository history
relicta notes

# Optionally request provider-generated prose (requires configured provider credentials)
relicta notes --ai

# Review the release before approval
relicta approve

# Publish after approval
relicta publish
```

The notes command supports audience, tone, language, and output options. In v4.2.0, `--ai` is a flag on `relicta notes`; it is not a flag on `relicta release`. Review generated notes and claims before approval.

## Common command reference

| Command | Purpose |
| --- | --- |
| `relicta init` | Initialize repository configuration in `.relicta.yaml`. |
| `relicta plan` | Analyze changes and recommend the next release version. |
| `relicta bump` | Apply the selected version to configured files. |
| `relicta notes` | Generate deterministic release notes; `--ai` enables provider-generated prose in v4.2.0. |
| `relicta approve` | Review the prepared release and approve it for publishing. |
| `relicta publish` | Execute the approved release, including configured tags and plugins. |
| `relicta status` | Show current release state. |
| `relicta mcp serve` | Start the MCP server for a connected agent. |

See the [workflow guide](/workflow), [configuration reference](/configuration), and [MCP integration guide](/mcp) for detailed setup.
